# Gerenciador de Tarefas em Java

Um projeto simples em Java para gerenciar tarefas por linha de comando. O programa permite adicionar, listar e remover tarefas de forma prática, utilizando apenas a biblioteca padrão do Java.

## Funcionalidades

- Adicionar nova tarefa
- Listar todas as tarefas cadastradas
- Remover uma tarefa pelo número da lista
- Encerrar o programa

## Estrutura do projeto

- `GerenciadorTarefas.java` — arquivo principal com a lógica do programa

## Como executar

1. Abra o terminal na pasta do projeto.
2. Compile o arquivo:

```bash
javac GerenciadorTarefas.java
```

3. Execute o programa:

```bash
java GerenciadorTarefas
```

## Exemplo de uso

Ao iniciar o programa, você verá um menu com as opções:

```text
--- Gerenciador de Tarefas ---
1. Adicionar tarefa
2. Listar tarefas
3. Remover tarefa
4. Sair
```

## Observação

Este projeto é uma implementação básica, ideal para aprender operações com `ArrayList`, entrada de dados via `Scanner` e controle de fluxo em Java.
